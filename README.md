# MKSUSH
Monitoring temperature + oil changing
💻 Utilisation
Ajouter un contrôle

Cliquez sur un jour du calendrier
Sélectionnez le type de contrôle
Pour température : entrez la valeur en °C
Pour huile/nettoyage : validez simplement
Cliquez "Enregistrer"

Modifier un contrôle

Survolez un contrôle dans le calendrier
Cliquez sur le crayon bleu (✎)
Modifiez les informations
Cliquez "Enregistrer"

Supprimer un contrôle

Survolez un contrôle dans le calendrier
Cliquez sur la poubelle rouge (🗑)
Confirmez la suppression

Consulter les statistiques

Naviguez vers le mois désiré
Les statistiques se mettent à jour automatiquement
Voir le taux de complétude pour chaque type de contrôle

Exporter les données

Cliquez sur "📥 Exporter en CSV" pour télécharger les données
Ouvrez le fichier dans Excel ou Google Sheets pour analyse

🔒 Sécurité & Données

Aucun serveur : Les données sont stockées localement dans votre navigateur
Aucune transmission : Vos données ne quittent jamais votre appareil
Backup : Sauvegardez votre navigateur pour ne rien perdre

⚠️ Important : Si vous videz votre cache/cookies, les données seront perdues. Pensez à exporter vos données régulièrement !
